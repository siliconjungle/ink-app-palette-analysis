Methods

The charts run DawnBringer’s original Analyze Palette V2.21 Lua script and colour library in a local WebAssembly worker.

Brightness: √(0.0676R² + 0.3025G² + 0.0361B²) × 1.5690256395005606. Colour matching uses DawnBringer’s weighted RGB / brightness distances. Purity, HSV and HSL are distinct selectable saturation measures.

Small image palettes retain exact RGB colours. Larger images use deterministic, alpha-weighted median-cut reduction to the selected colour limit. Fully transparent pixels are ignored. The charts treat palette entries equally, as the original analyser does.

Useful mixes and neutralisers retain the original 64-colour limit. Use a smaller palette to display them. The DB32 arrangement regroups the same V2.21 chart results; it does not claim to reproduce the older V1 pixel raster exactly.

Local images are imported into the Ink file system when opened. Colour calculations stay in your browser. Saving adds the report PNG and a database record linking it to the source image, palette and settings.
